# 내가 폐기한 캐릭터들이 최종보스가 되었다. — World Introduction Prototype

정적 HTML/CSS/JS로 만든 세계관 소개 웹사이트 프로토타입입니다.

구성 순서:
1. 세계관 개요
2. 세계관 설명
3. 인물 카드

## 파일
- `index.html` — 페이지 구조와 세계관 콘텐츠
- `styles.css` — 반응형 다크 판타지 UI
- `script.js` — 인물 카드 데이터, 필터, 검색, 스크롤 등장 효과

## GitHub Pages
Repository Settings → Pages에서 `Deploy from a branch`를 선택하고 `main / (root)`를 지정하면 정적 사이트로 공개할 수 있습니다.
